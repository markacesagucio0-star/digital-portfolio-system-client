    1. open yung xampp (pag may error, run nyu as administrator)
        - pano mag open ng command prompt sa vs-code?

            a. punta sa top left section ng vscode and click the terminal (pag walang terminal may 3 dots jan, click nyu yun andoon yung terminal) and then a menu will appear at clikc nyo yung new terminal, do this 2 times.

    2. open kayo ng dalawang command prompts sa vs code and yung isa change directory nyu sa server folder "cd server" - type nyu lang yung command na yan sa command prompt pag open nyu.

    3. sa command promt ng server na kung saan nag change directory kau sa server folder type nyu "bun run dev"

    4. then sa isang command prompt naman type nyu "npm run dev" tapos open ng browser and type nyu yung url na "http://localhost:5173" or kaya control + click nyu yung naka underline jan (pag nasa vs code ka lang) 

    5. then tapos nun nasa server na kau
